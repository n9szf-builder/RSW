# Rib Side Works (RSW)

Milwaukee Road models in OpenSCAD - passenger cars, caboose, stations - printed mainly in G scale (1:29), with O and HO versions.

Models are free for personal use. For commercial use, contact the owner.

The OpenSCAD kits for all 52 passenger cars are here in G (1:29), O (1:48) and HO (1:87), in each car's `Kit` folder. See [BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md). Requires OpenSCAD 2025 or newer.

More coming soon: build books and the MR Print Files program.
